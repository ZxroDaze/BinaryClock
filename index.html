Binary Clock

Each column of squares is one digit of time. A lit square is a 1, worth 8, 4, 2 or 1. Add up the lit squares to get the digit.

1 · A bit

A bit is the smallest piece of information a computer has: a switch that is either off (0) or on (1). Everything on your screen, every song and every game is built from billions of these. Click the square.

0 (off)

2 · Four bits make a number

One bit only counts 0 or 1. Put four in a row and give each a different weight: 8, 4, 2 and 1. Add up the weights of the lit squares and you get a number. Click the squares.

Four bits can make 0 to 15. A clock digit only needs 0 to 9.

3 · Why six columns?

The clock does not store 13:07:45 as three big numbers. It splits each into two digits (a tens digit and a units digit), and gives every digit its own column of four squares. Type a number from 0 to 99.

Tens digit = divide by 10 and drop the remainder. Units digit = the remainder.

4 · How the computer tests a bit

For each square, the code asks: is this weight part of the number? It uses & (AND), which keeps only the bits two numbers share. If the answer is not 0, the square lights up. Type a number from 0 to 15, since four squares can show that much.
